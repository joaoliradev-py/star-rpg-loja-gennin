Técnica de Divisão

Rank: S

Suplementar

Ck p/Uso: 100.000

|| Esta técnica permite ao usuário se dividir literalmente em duas cópias totalmente independentes e idênticas de si mesmo. Ao contrário das técnicas de clonagem comuns, trata-se de uma separação física que não exige selos de mão para ativar, tornando o processo instantâneo. Isso significa que, mesmo que um dos corpos seja incapacitado, o outro permanece ileso e nenhum pode ser considerado estritamente o "original", não sendo dissipados como clones normais. No entanto, durante a divisão, o poder do usuário é reduzido pela metade, ficando impossibilitado de usar técnicas altamente complexas como a Kekkei Tōta. { Divide os atributos em 50/50, criando outro clone de si mesmo; o clone recebe todos os ativos atuais (não recebe bônus de modos ativos); pode utilizar todas as técnicas do usuário, exceto Kekkei Tōta; só é possível criar um novo clone após a morte do anterior; o usuário pode alternar sua consciência entre os clones e, quando um é derrotado, recupera os atributos integralmente. } 🪨 ( A divisão é considerada Rank 2. ).|| 3x
